# 🐍 Snake Game - Jogo da Cobrinha

Bem-vindo ao **Snake Game**, um jogo clássico da cobrinha desenvolvido com **HTML5**, **CSS3** e **JavaScript puro**! 🎮

## 📜 Sobre o projeto

Este projeto recria o famoso jogo da cobrinha, mas com algumas melhorias visuais e funcionais:
- 🟦 **Fundo com céu azul e nuvens brancas** para um visual agradável.
- 🍎 **Comida estilizada como uma maçã** com folha verde.
- 🐍 **Cobra mais realista**, com:
  - Cabeça com olhos e língua.
  - Corpo com efeito de gradiente.

## 🕹️ Como jogar

1. Use as **setas direcionais** do teclado para controlar a cobra:
   - ⬆️ **Seta para cima**: Move a cobra para cima.
   - ⬇️ **Seta para baixo**: Move a cobra para baixo.
   - ⬅️ **Seta para esquerda**: Move a cobra para a esquerda.
   - ➡️ **Seta para direita**: Move a cobra para a direita.
2. O objetivo é comer a maçã 🍎 para crescer e aumentar sua pontuação.
3. O jogo termina se a cobra colidir com as bordas ou com o próprio corpo.
